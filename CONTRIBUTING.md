# Contributing

Conventions pour le projet La Grande Revelation.

## Branches

- `main` : branche principale, toujours deployable.
- `feat/<nom>` : nouvelle fonctionnalite.
- `fix/<nom>` : correction de bug.
- `docs/<nom>` : documentation.

## Commits

Utiliser des messages clairs, idealement au format Conventional Commits :

- `feat: ...`
- `fix: ...`
- `docs: ...`
- `style: ...`
- `perf: ...`

## Pull Requests

- Une PR par issue.
- Referencer l'issue avec `Closes #<numero>`.
- Remplir le template de PR.
- Demander une review avant merge.

## Style de code

- HTML/CSS indentes, balises semantiques, convention de nommage en anglais.
- Commenter le code source.

## Sources

Citer toutes les sources utilisees (images, polices, snippets).
